# Add opt-in daily file logging for LLM calls

## Description

Add an AgentMap configuration option (off by default) to write a dedicated local LLM call log. Write one record per provider attempt, including retries and fallbacks, using a date-stamped file per UTC day. Record request_datetime, response_datetime, provider, input_tokens, output_tokens, was_success, and error_message. For failures with no response, leave response_datetime unset; leave unavailable usage unset and record a sanitized error message. The logger works independently of OpenTelemetry. Retention, compression, and cleanup are handled externally.

## Justification

Give AgentMap operators a local record of provider calls for investigating usage and unexpected billing.

## Impact Analysis

AgentMap operators can inspect a local, daily log even when telemetry is disabled. The existing LLM cost receipts and provider-attempt hooks in E05-F06 are relevant context for locating provider calls and obtaining usage data.

## Rollback Plan

Disable the file logger in AgentMap configuration to stop new writes. Existing log files follow the operator's external retention policy.
